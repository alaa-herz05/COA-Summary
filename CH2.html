Instruction Set Architecture (ISA)

معمارية مجموعة التعليمات
What is an Instruction Set? ما هي مجموعة التعليمات؟

An instruction set is the collection of commands that a CPU can understand and execute. These commands are represented internally as machine language — 0s and 1s.

  • Different computers may have different instruction sets.
  • Most ISAs share common ideas: arithmetic, data transfer, logic, branches, and jumps.
  • ISA is the contract between software and hardware.
Arabic Explanation
مجموعة التعليمات هي اللغة التي يفهمها المعالج. البرنامج الذي تكتبه بلغة C أو Java لا يفهمه المعالج مباشرة، لذلك يُترجم إلى تعليمات بلغة الآلة: 0 و 1. الـ ISA تحدد شكل هذه التعليمات، السجلات، طريقة الوصول للذاكرة، وأنواع العمليات.

RISC vs CISC

المقارنة بين RISC و CISC
CISC تعليمات معقدة

Complex Instruction Set Computer

  • Large number of instructions.
  • Variable instruction length.
  • A single instruction may perform multiple operations.
  • Hardware and decoding are more complex.
mov ax, 10
mov bx, 5
mul bx
Arabic
CISC تعني أن المعالج يمتلك تعليمات كثيرة ومعقدة. أحياناً تعليمة واحدة تعمل أكثر من خطوة، لذلك البرنامج يكون أقصر لكن التنفيذ وفك الترميز أعقد.
RISC تعليمات مخفضة وبسيطة

Reduced Instruction Set Computer

  • Small but complete instruction set.
  • Fixed instruction length.
  • One instruction usually performs one simple operation.
  • Faster execution and easier pipelining.
mov ax, 0
mov bx, 10
mov cx, 5
Loop: add ax, bx
      loop Loop
Arabic
RISC تعتمد على تعليمات بسيطة وسريعة. كل تعليمة تعمل عملية واحدة غالباً، لذلك عدد التعليمات قد يزيد لكن كل تعليمة أسرع وأسهل على المعالج.
Formal Comparison جدول المقارنة الرسمي
PropertyRISCCISC
Instruction CountFewMany
Instruction LengthFixed sizeVariable size
ExecutionFast/simpleMay be slower/complex
Memory AccessExplicit load/store onlyMany instructions can access memory

ExamplesMIPS, ARM, SPARCIntel x86
Performance idea: RISC reduces time by reducing clock cycles per instruction. CISC tries to reduce the number of instructions per program.
Arabic Summary
RISC أسرع لأن التعليمات بسيطة وثابتة الحجم. CISC يحاول تقليل عدد التعليمات، لكن التعليمة نفسها قد تكون أبطأ وأعقد.
Clock Cycle Example مثال دورات الساعة

CISC multiplication may use fewer instructions but one complex instruction can take many cycles.

CISC
(2 mov × 1 cycle) + (1 mul × 30 cycles) = 32 cycles
RISC
(3 mov × 1 cycle) + (5 add × 1 cycle) + (5 loop × 1 cycle) = 13 cycles
Arabic
رغم أن CISC يستخدم تعليمات أقل، تعليمة مثل mul قد تكون بطيئة جداً. RISC يستخدم تعليمات أكثر لكنها بسيطة وسريعة، لذلك قد يكون المجموع أقل.

MIPS Architecture & Design Principles

معمارية MIPS ومبادئ التصميم
MIPS Overview نظرة عامة

MIPS = Microprocessor without Interlocked Pipeline Stages. It is a RISC ISA used as the main example in this chapter.

  • 32-bit instruction words.
  • 32 registers, each 32 bits.
  • Load/store architecture.
  • Simple and regular instruction formats.
Arabic
MIPS معمارية RISC تعليماتها بسيطة وثابتة الحجم، وتستخدم كثيراً في شرح مبادئ تنظيم الحاسوب لأنها واضحة ومنتظمة.

Arithmetic and Immediate Operations

العمليات الحسابية والفورية
Arithmetic Format شكل العمليات الحسابية

MIPS arithmetic instructions usually use three operands: destination, source 1, source 2.

add $t0, $s1, $s2   # $t0 = $s1 + $s2
sub $t0, $s1, $s2   # $t0 = $s1 - $s2
Arabic
العملية الحسابية في MIPS غالباً تأخذ 3 معاملات: مكان النتيجة ثم أول مصدر ثم ثاني مصدر.
Example: C to MIPS مثال تحويل من C إلى MIPS

C code:

f = (g + h) - (i + j);

Assume: f=$s0, g=$s1, h=$s2, i=$s3, j=$s4

add $t0, $s1, $s2   # $t0 = g + h
add $t1, $s3, $s4   # $t1 = i + j
sub $s0, $t0, $t1   # f = $t0 - $t1
Arabic Steps
نحسب أول قوس في سجل مؤقت، ثم نحسب القوس الثاني في سجل مؤقت آخر، ثم نطرح النتيجتين ونضعها في f.
Immediate Operand المعامل الفوري

An immediate is a constant stored directly inside the instruction.

addi $s3, $s3, 4    # $s3 = $s3 + 4
addi $s2, $s1, -1   # $s2 = $s1 - 1
No subtract immediate: use addi with a negative constant.
Arabic
إذا أردت طرح عدد ثابت، استخدم addi مع رقم سالب. مثال: addi $s2,$s1,-1 تعني s2 = s1 - 1.
The Constant Zero السجل صفر

$zero always contains 0 and cannot be overwritten.

add $t2, $s1, $zero   # copy $s1 into $t2
Arabic
السجل $zero قيمته دائماً صفر. نستخدمه للنسخ أو المقارنات أو عمليات أخرى تحتاج صفر.

Memory Operands: lw and sw

تعليمات الذاكرة: تحميل وتخزين
Byte Addressing and Word Alignment العنونة بالبايت ومحاذاة الكلمة
  • Memory is byte-addressed: each address refers to 8 bits.
  • A word = 4 bytes = 32 bits.
  • Word addresses should be multiples of 4.
  • MIPS is Big Endian: most significant byte is stored at the smallest address.
Array Offset Rule
Offset = index × 4 bytes
Arabic
كل عنصر int في MIPS حجمه 4 بايت، لذلك عند الوصول إلى A[8] نضرب 8 × 4 = 32.
Example 1: Load Array Element مثال تحميل عنصر مصفوفة

C code:

g = h + A[8];

Assume: g=$s1, h=$s2, base address of A=$s3

lw  $t0, 32($s3)    # $t0 = A[8]
add $s1, $s2, $t0   # g = h + A[8]
Arabic
نحمّل A[8] من الذاكرة إلى $t0، ثم نجمعه مع h ونضع النتيجة في g.
Example 2: Store Array Element مثال تخزين في المصفوفة

C code:

A[12] = h + A[8];
lw  $t0, 32($s3)    # $t0 = A[8]
add $t0, $s2, $t0   # $t0 = h + A[8]
sw  $t0, 48($s3)    # A[12] = $t0
Why offsets?
A[8] → 8 × 4 = 32 A[12] → 12 × 4 = 48

Signed and Unsigned Numbers

الأعداد الموقعة وغير الموقعة
Unsigned Binary Integers الأعداد الثنائية غير الموقعة

Unsigned numbers represent only non-negative values.

Range
n-bit unsigned range = 0 to 2^n - 1
1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
      = 8 + 0 + 2 + 1 = 11₁₀
Arabic
إذا العدد unsigned فلا يوجد إشارة سالبة. كل البتات تُستخدم لتمثيل القيمة فقط.
Two's Complement Signed Integers الأعداد الموقعة بطريقة متمم الاثنين

In 2's complement, the leftmost bit is the sign bit: 0 = non-negative, 1 = negative.

Range
n-bit signed range = -2^(n-1) to +2^(n-1)-1
BitsSigned RangeUnsigned Range
8-128 to +1270 to 255
16-32768 to +327670 to 65535
32-2,147,483,648 to +2,147,483,6470 to 4,294,967,295
Arabic
في 2's complement أول بت من اليسار هو بت الإشارة. إذا كان 0 فالعدد موجب أو صفر، وإذا كان 1 فالعدد سالب.
One's Complement متمم الواحد

Flip every bit: 0 becomes 1 and 1 becomes 0.

+5 = 00000101
1's complement = 11111010
Two's Complement متمم الاثنين

Flip every bit, then add 1.

+5 = 00000101
Flip = 11111010
+ 1  = 11111011
So -5 = 11111011
Worked Examples أمثلة محلولة
Find -13 in 8-bit 2's complement
+13 = 00001101
Flip = 11110010
+ 1  = 11110011
Answer = 11110011
Convert 11110110 to decimal
MSB = 1 → negative
Flip = 00001001
+ 1  = 00001010 = 10
Answer = -10
Arabic Exam Trick
إذا أول بت = 1 فالعدد سالب. لمعرفة قيمته: اقلب البتات ثم أضف 1 ثم ضع إشارة سالبة.
Sign Extension توسيع الإشارة

When increasing the number of bits, preserve the value by copying the sign bit to the left.

+2: 00000010 → 00000000 00000010
-2: 11111110 → 11111111 11111110
Arabic
في الأعداد الموجبة نضيف أصفاراً من اليسار. في الأعداد السالبة نكرر 1 من اليسار حتى تبقى القيمة نفسها.

Representing Instructions

تمثيل التعليمات داخل الحاسوب
Machine Code لغة الآلة

Instructions are encoded as binary numbers. In MIPS, each instruction is a 32-bit instruction word.

Arabic
تعليمة Assembly مثل add أو lw يتم تحويلها إلى 32 بت داخل المعالج. هذا التمثيل الثنائي يسمى Machine Code.
R-Format صيغة R

Used for register-register operations such as add, sub, and, or.

R-format fields
| op (6) | rs (5) | rt (5) | rd (5) | shamt (5) | funct (6) |
FieldMeaning
opOperation code. For R-format usually 0.
rsFirst source register.
rtSecond source register.
rdDestination register.
shamtShift amount.
functFunction code that specifies exact operation.
R-format Example: add $t0,$s1,$s2 مثال صيغة R
Register numbers
$s1 = 17, $s2 = 18, $t0 = 8
Decimal fields
op=0, rs=17, rt=18, rd=8, shamt=0, funct=32
Binary fields
000000 10001 10010 01000 00000 100000
Machine code
00000010001100100100000000100000₂ = 0x02324020
Arabic Steps
نحدد نوع التعليمة R-format، ثم نكتب أرقام السجلات، ثم نحول كل حقل إلى عدد البتات الخاص به، وفي النهاية نجمع الحقول لتكوين 32 بت.
I-Format صيغة I

Used for immediate arithmetic and load/store/branch instructions.

I-format fields
| op (6) | rs (5) | rt (5) | constant/address (16) |
  • addi: rt is destination.
  • lw: rt is destination, rs is base.
  • sw: rt is source, rs is base.
  • beq/bne: rs and rt are compared.
Arabic
صيغة I تستخدم عندما يوجد رقم ثابت immediate أو عنوان إزاحة offset مثل lw و sw و addi و beq و bne.
Hexadecimal النظام السادس عشر

Hex is a compact way to represent binary. Every hex digit equals 4 bits.

Logical and Shift Operations

العمليات المنطقية والإزاحة
Logical Operations العمليات المنطقية
OperationC/JavaMIPSUse
AND&and, andiMask bits / clear bits
OR|or, oriSet bits
NOT~nor with $zeroInvert bits
1010 AND 1100 = 1000
1010 OR  1100 = 1110
NOT 1100 = 0011
Arabic
AND تستخدم لإخفاء أو تصفير بعض البتات. OR تستخدم لجعل بعض البتات 1. أما NOT في MIPS تُنفذ غالباً باستخدام nor مع $zero.
NOR as NOT استخدام NOR كـ NOT
nor $t0, $t1, $zero
# $t0 = NOT($t1 OR 0) = NOT($t1)

sll — Shift Left Logical
sll by i bits = multiply by 2^i
0010 << 2 = 1000

srl — Shift Right Logical
srl by i bits = divide by 2^i
1000 >> 2 = 0010
8 ÷ 4 = 2
Arabic
الإزاحة لليسار تضاعف العدد بقوى 2. الإزاحة لليمين تقسم العدد على قوى 2، وتستخدم هنا للأعداد غير الموقعة.

Decision Instructions: Branch and Jump

تعليمات اتخاذ القرار: التفرع والقفز
Conditional Operations عمليات الشرط
InstructionMeaning
beq rs, rt, L1Branch to L1 if rs == rt
bne rs, rt, L1Branch to L1 if rs != rt
j L1Unconditional jump to L1
Arabic
beq تعني اقفز إذا القيمتان متساويتان. bne تعني اقفز إذا القيمتان غير متساويتين. j تعني اقفز بدون شرط.
Compiling If-Else تحويل if-else إلى MIPS

C code:

if (i == j)
    f = g + h;
else
    f = g - h;

Assume: f=$s0, g=$s1, h=$s2, i=$s3, j=$s4

bne $s3, $s4, Else   # if i != j go to Else
add $s0, $s1, $s2    # f = g + h
j   Exit             # skip else
Else:
sub $s0, $s1, $s2    # f = g - h
Exit:
Arabic Steps
نستخدم bne بعكس الشرط حتى نذهب إلى Else عندما لا يتحقق الشرط. بعد تنفيذ حالة if نستخدم j Exit حتى لا ننفذ else.
Branch Addressing عنونة التفرع

Branches use PC-relative addressing. The target is calculated relative to the PC.

Branch Target
Target address = PC + offset × 4 PC is already incremented by 4
Arabic
تعليمات branch غالباً تقفز لمسافة قريبة للأمام أو للخلف، لذلك تخزن offset وليس العنوان الكامل.
Jump Addressing عنونة القفز

Jump uses pseudo-direct addressing and stores a 26-bit address field.

Jump Target
Target address = PC[31..28] : (address × 4)
Arabic
تعليمة jump يمكن أن تقفز إلى مكان أبعد داخل text segment لذلك تستخدم حقل عنوان أكبر من branch.

Assembly Translation Examples

أمثلة إضافية على التحويل إلى Assembly
Example A مثال أ

C code:

a = b + c + d;

Assume: a=$s0, b=$s1, c=$s2, d=$s3

add $t0, $s1, $s2   # temp = b + c
add $s0, $t0, $s3   # a = temp + d
Arabic
لأن add تأخذ مصدرين فقط، نستخدم سجل مؤقت لحساب b+c ثم نضيف d.
Example B مثال ب

C code:

x = y - (z + 10);

Assume: x=$s0, y=$s1, z=$s2

addi $t0, $s2, 10   # temp = z + 10
sub  $s0, $s1, $t0  # x = y - temp
Example C: Array مثال مصفوفة

C code:

B[5] = A[3] + 7;

Assume: base A=$s1, base B=$s2

lw   $t0, 12($s1)   # A[3], because 3×4=12
addi $t0, $t0, 7    # A[3]+7
sw   $t0, 20($s2)   # B[5], because 5×4=20
