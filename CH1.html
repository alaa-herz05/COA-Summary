The Computer Revolution

ثورة الحاسوب
Why Computer Technology Matters لماذا تطورت الحواسيب؟

Progress in computer technology, supported by Moore’s Law, made new applications possible: automobiles, cell phones, the human genome project, the World Wide Web, search engines, and many embedded systems.

  • Computers are pervasive: they are everywhere, not only on desks.
  • Improvement in technology means higher capacity, better performance, and lower cost.
Arabic Explanation
الفكرة الأساسية: تطور الحواسيب جعلها تدخل كل شيء في حياتنا: السيارات، الهواتف، الإنترنت، محركات البحث، والأجهزة الذكية. السبب الرئيسي هو تحسن التكنولوجيا مع الوقت: أداء أعلى، سعة أكبر، وسعر أقل.
Moore’s Law قانون مور

Moore’s Law is the observation that the number of transistors on chips increased rapidly over time, enabling more performance and lower cost per computation.

Exam idea: Design must anticipate future technology because chip capacity continues to improve.
Arabic
قانون مور يعني أن عدد الترانزستورات على الشريحة يزداد مع الزمن، وهذا يؤدي إلى معالجات أقوى وأرخص. لذلك المصممون يبنون الأنظمة وهم يتوقعون أن التكنولوجيا ستتحسن.

Performance: Response Time and Throughput

الأداء: زمن الاستجابة والإنتاجية
Defining Performance تعريف الأداء
Response Time
How long it takes to complete one task.
Throughput
Total work done per unit time, e.g., tasks per hour.
Arabic
زمن الاستجابة يعني كم يستغرق تنفيذ مهمة واحدة. الإنتاجية تعني كم مهمة ينجز النظام في فترة زمنية.
Relative Performance الأداء النسبي
Performance Definition
Performance = 1 / Execution Time
How many times faster?
Performance_X / Performance_Y = ExecutionTime_Y / ExecutionTime_X
Solved Example
Program time on A = 10s, on B = 15s.
ExecutionTime_B / ExecutionTime_A = 15 / 10 = 1.5
So, A is 1.5 times faster than B.
Arabic
الأسرع هو الذي زمن تنفيذه أقل. إذا A أخذ 10 ثواني وB أخذ 15 ثانية، نقسم زمن الأبطأ على زمن الأسرع: 15/10 = 1.5، إذن A أسرع 1.5 مرة.

Measuring Execution Time

قياس زمن التنفيذ
Elapsed Time vs CPU Time الزمن الكلي وزمن المعالج
MeasureMeaningIncludesبالعربي
Elapsed TimeTotal response timeCPU, I/O, OS overhead, idle timeالزمن الكامل من البداية للنهاية
CPU TimeTime CPU spends processing this jobUser CPU time + system CPU timeزمن المعالج فقط لتنفيذ المهمة
Arabic
Elapsed Time يشمل كل شيء حتى الانتظار و I/O. أما CPU Time فهو الزمن الذي قضاه المعالج فعلياً في تنفيذ البرنامج.
CPU Clocking ساعة المعالج

Digital hardware is governed by a constant-rate clock.

Definitions
Clock period = duration of one clock cycle Clock frequency = cycles per second Clock frequency = 1 / Clock period
Example
Clock period = 250 ps = 0.25 ns
Clock rate = 1 / 0.25 ns = 4 GHz
Arabic
كل عملية في المعالج تمشي حسب نبضات الساعة. كلما قل زمن الدورة Clock Period زاد التردد Clock Rate.

CPU Performance Equations

معادلات أداء المعالج
CPU Time Equations القوانين الأساسية
CPU Time
CPU Time = CPU Clock Cycles × Clock Cycle Time
Using Clock Rate
CPU Time = CPU Clock Cycles / Clock Rate
Instruction Count and CPI
CPU Clock Cycles = Instruction Count × CPI
Complete Formula
CPU Time = Instruction Count × CPI × Clock Cycle Time CPU Time = (Instruction Count × CPI) / Clock Rate
Arabic
زمن التنفيذ يعتمد على ثلاث أشياء: عدد التعليمات IC، عدد الدورات لكل تعليمة CPI، وزمن الدورة أو تردد الساعة. لتقليل الزمن: قلل IC أو CPI أو Cycle Time.
CPU Time Example مثال محلول

Computer A: 2 GHz clock, 10s CPU time.
Computer B: target CPU time = 6s, but it needs 1.2 × the clock cycles of A. Find B clock rate.

Solution
Cycles_A = Time_A × Rate_A = 10 × 2GHz = 20 billion cycles Cycles_B = 1.2 × Cycles_A = 24 billion cycles Rate_B = Cycles_B / Time_B = 24 / 6 = 4 GHz
Arabic
نحسب دورات A أولاً: 10 × 2GHz = 20 مليار دورة. B يحتاج 1.2 من هذه الدورات = 24 مليار. حتى ينهي خلال 6 ثواني: 24/6 = 4GHz.

Instruction Count and CPI

عدد التعليمات و CPI
Instruction Count and CPI تعريفات مهمة
  • Instruction Count (IC): number of instructions executed by a program.
  • CPI: average cycles per instruction.
  • IC is affected by program, ISA, and compiler.
  • CPI is affected by CPU hardware and instruction mix.
Arabic
IC هو عدد التعليمات. CPI هو متوسط عدد دورات الساعة لكل تعليمة. البرنامج والمترجم يؤثران على IC، والهاردوير ونوع التعليمات يؤثران على CPI.
CPI Example 1 مثال مقارنة A و B

Computer A: Cycle Time = 250 ps, CPI = 2.0
Computer B: Cycle Time = 500 ps, CPI = 1.2
Same ISA → same instruction count.

CPU Time per instruction
A = CPI × Cycle Time = 2.0 × 250ps = 500ps B = 1.2 × 500ps = 600ps
Answer: A is faster. Speedup = 600 / 500 = 1.2 times faster.
Arabic
بما أن ISA نفسها، نفترض IC متساوي. نقارن CPI × Cycle Time. A = 500ps و B = 600ps، إذن A أسرع بمقدار 1.2 مرة.
Weighted Average CPI متوسط CPI الموزون
Weighted CPI
Average CPI = Σ(CPI_i × Frequency_i)

If instruction counts are given:

Using Counts
Average CPI = Total Clock Cycles / Total Instruction Count
Arabic
إذا كانت أنواع التعليمات مختلفة، نحسب CPI متوسط حسب تكرار كل نوع. وإذا عندك أعداد التعليمات، اجمع الدورات كلها ثم اقسم على عدد التعليمات الكلي.
CPI Example 2 — Code Sequences مثال التسلسلات
ClassABC
CPI123
Sequence 1 IC212
Sequence 2 IC411
Sequence 1
Clock Cycles = 2×1 + 1×2 + 2×3 = 10 IC = 5 Average CPI = 10 / 5 = 2.0
Sequence 2
Clock Cycles = 4×1 + 1×2 + 1×3 = 9 IC = 6 Average CPI = 9 / 6 = 1.5
Important: Sequence 2 has more instructions but fewer total cycles, so it is faster if clock cycle time is the same.
Arabic
ليس دائماً عدد التعليمات الأقل يعني أسرع. التسلسل الثاني عنده IC أكبر، لكن عدد الدورات أقل، لذلك يكون أسرع إذا نفس زمن الدورة.

Multiprocessors and Parallelism

المعالجات المتعددة والتوازي
Why Multiprocessors? لماذا انتقلنا للمعالجات المتعددة؟

Uniprocessor performance became constrained by power, instruction-level parallelism, and memory latency. Modern chips use multicore processors: more than one processor core on a chip.

  • Parallel programming is required to fully benefit.
  • Programs need load balancing.
  • Communication and synchronization must be optimized.
Arabic
لأن رفع سرعة النواة الواحدة أصبح محدوداً بالطاقة والحرارة، اتجهت الشركات إلى وضع عدة أنوية داخل نفس الشريحة. لكن للاستفادة منها يجب كتابة البرامج بطريقة متوازية.
Parallelism Types أنواع التوازي
TypeDescriptionVisible to Programmer?
Instruction-Level ParallelismHardware executes multiple instructions at onceNo, mostly hidden
Multicore ParallelismMultiple cores run different tasks/threadsYes, programmer often must help

A program takes 8s on A and 12s on B. How much faster is A?

Clock cycles = 30 billion, clock rate = 3GHz. CPU time?
Answer: CPU Time = 30 / 3 = 10 seconds.

Power Equation & Performance Trade-offs

قانون الطاقة (Power) وأمثلة الامتحان
CMOS Power Formula قانون الطاقة
Power ∝ Capacitive Load × Voltage² × Frequency
Increasing voltage has a much larger effect because power depends on Voltage².
Arabic
الطاقة المستهلكة تعتمد على ثلاثة عوامل: السعة الكهربائية (Capacitive Load)، الجهد (Voltage)، والتردد (Frequency). الجهد هو الأكثر تأثيراً لأنه مرفوع للأس 2.
Important Rules قواعد مهمة
  • If Frequency doubles → Power doubles.
  • If Voltage doubles → Power becomes 4 times larger.
  • If Voltage increases by 10% → Power increases by (1.1)².
Arabic
مضاعفة التردد تضاعف الطاقة. أما مضاعفة الجهد فتجعل الطاقة تزداد أربع مرات.
Solved Example 1 مثال محلول 1
Old Frequency = 2 GHz
New Frequency = 4 GHz

Power Ratio = 4 / 2 = 2

Answer: Power doubles.

Solved Example 2 مثال محلول 2
Old Voltage = 1V
New Voltage = 2V

Power Ratio = (2²)/(1²)
            = 4

Answer: Power becomes 4× larger.

Solved Example 3 مثال محلول 3
Voltage increases from 1V to 1.5V

Power Ratio = (1.5²)/(1²)
            = 2.25

Answer: Power increases by 2.25×.

Exam Questions أسئلة امتحان
Q1: If frequency increases by 50%, what happens to power?
Answer: Power increases by 50%.
Q2: If voltage increases from 1V to 3V?
Answer: Power = 3² = 9 times larger.
Q3: Which affects power more, voltage or frequency?
Answer: Voltage, because it is squared.
Q4: Why can't we keep increasing clock frequency forever?
Answer: Because of the Power Wall (heat and energy limits).
